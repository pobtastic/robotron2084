C531: Wave Sprite Frame Counter
Frame counter for the wave start sprite animation. Initialised to 0E by Initialise_Wave_Start_Sprites and decremented each frame by Animate_Wave_Start_Sprites; when it reaches zero the closing sprite is drawn and the animation restarts.
