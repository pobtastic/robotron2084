C6CE: Lookup Vector Table Entry
Returns the sprite pixel data pointer for entity type A from the table at Sprite_Pixel_Data_Table.
Input
A Entity type index
Output
DE Sprite pixel data pointer
LookupVectorTableEntry C6CE ADD A,A Double A to form the word-stride index into Sprite_Pixel_Data_Table.
C6CF LD HL,$C60C Point HL at the sprite pixel data table at Sprite_Pixel_Data_Table.
C6D2 LD D,$00 Form the word offset in DE (D=00 E=A).
C6D4 LD E,A
C6D5 ADD HL,DE Advance HL to the sprite data entry.
C6D6 LD E,(HL) Load the sprite pixel data pointer into DE.
C6D7 INC HL
C6D8 LD D,(HL)
C6D9 RET Return.
